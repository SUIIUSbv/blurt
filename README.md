# Blurt site

Public pages for the Blurt Chrome extension, served by GitHub Pages at https://suiiusbv.github.io/blurt/

- `index.html`: product page
- `privacy/`: privacy policy (linked from the Chrome Web Store listing). Keep it in sync with `docs/privacy-policy.md` in the extension repo.
- `status/`: status page, linked from Blurt's "Extraction failed" message. To change the status, edit the marked block in `status/index.html`.
